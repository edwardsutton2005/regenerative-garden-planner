# Regenerative Garden Planner

## Vision

An interactive garden-planning tool that makes designing a regenerative
garden feel like a strategy game.

Users place plants spatially and receive immediate feedback about whether
their layout works well.

## V1 Goal

Create a fun interactive garden sandbox based primarily on companion
planting relationships.

## V1 Features

- Interactive garden grid
- Plant palette
- Place plants onto cells
- Remove/move plants
- Plant spacing
- Positive companion relationships
- Negative companion relationships
- Immediate visual feedback
- Simple garden compatibility score

## Initial plant dataset

Start with approximately 15–20 common garden plants.

## Explicitly Not V1

- AI recommendations
- User accounts
- Native plant recommendations
- Weather
- Soil simulation
- Water simulation
- Supabase
- Multiplayer
- 3D graphics
- Mobile app
